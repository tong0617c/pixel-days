# 拾光小田 · Pixel Days

手机优先的像素风日程本。纯静态 HTML、CSS、JavaScript，可直接部署 GitHub Pages。

功能：按日期管理每日任务、勾选完成、日程时间、手动输入专注时长、修改和删除记录、周专注统计、JSON 导入导出。

数据仅保存在当前域名下的浏览器 localStorage；不上传 GitHub，不自动跨设备同步。更换浏览器或清理数据前请导出备份。浏览器隐私模式可能无法持久保存。

像素插画为本项目原创 SVG。字体使用 Google Fonts 的 Noto Sans SC，网络不可用时回退系统字体。

部署：将本目录内容放入 GitHub 仓库根目录，在 Settings → Pages 选择 Deploy from a branch → main → /(root)。
